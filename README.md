A forge-master timing game — pick an order, strike true, quench white-hot.
Entry for [make.fun best-game-01](https://make.fun/bounty/best-game-01).

## How to play

Open `game/index.html` in a desktop browser (served by any static HTTP server)
and play with keyboard and mouse. Take a customer's order, time your hammer
strikes, and quench the blade white-hot to score. Complete orders to win.

## Build

`main.ts` copies `game/` and `screenshots/` to the output directory and writes
`dossier.json` (see the competition kit for details). No build step is needed
to play the game itself — it is plain static files under `game/`.
